# **Feature Extraction Analysis of Pre-trained DNNs Before and After Fine-Tuning**

## **1. Introduction**

This study investigates the feature extraction capabilities of a Deep Neural Network (DNN) pre-trained on the ImageNet dataset. The goal is to analyze how feature representations change before and after fine-tuning on domain-specific datasets. The evaluation is conducted on two tasks: face recognition and object recognition (flowers).

---

## **2. Model Selection**

A pre-trained Convolutional Neural Network (CNN) is selected from the following options:

* ResNet (e.g., ResNet50)
* VGG (e.g., VGG16)
* MobileNet (e.g., MobileNetV2)

The selected model is initialized with ImageNet pre-trained weights.

---

## **3. Experimental Setup**

### **3.1 Face Recognition Task**

* **Training & Validation Dataset:** Publicly available face dataset (e.g., LFW, CelebA)
* **Test Dataset:** Custom dataset consisting of images of friends and/or relatives

### **3.2 Object Recognition Task (Flowers)**

* **Training & Validation Dataset:** CIFAR-10 dataset
* **Test Dataset:** Custom collected flower images

---

## **4. Feature Extraction**

Feature vectors are extracted from an intermediate layer (preferably the penultimate layer) of the CNN under two conditions:

### **4.1 Before Fine-Tuning**

* Use the pre-trained ImageNet weights directly
* Extract feature embeddings without modifying the model

### **4.2 After Fine-Tuning**

* Fine-tune the model on the respective task-specific datasets
* Extract feature embeddings again from the same layer
